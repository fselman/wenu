# Research dossier: 77 stellar-designation review cases

Research date: 2026-10-06. Baseline: `04cc3c1aab5e88a9c5d51f56cb07eada62f4951e`.

- [PDF dossier](wenu-77-case-dossier.pdf) — 45-page document for review.
- [Searchable HTML dossier](wenu-77-case-dossier.html) — the same individual investigations with source links.
- [Structured research records](wenu-77-case-research.json) — classifications, evidence, uncertainties and proposed reporting metadata for all 77 cases.

The research distinguishes historically valuable alternate designations from
system/component scope, superscript conventions, competing letter traditions,
identity/cross-index problems and Latin-letter case differences. Historical
aliases such as Alpheratz's α And and δ Peg are preserved as evidence rather
than treated automatically as errors.

All 77 cases remain `pending_fernando`; every `decision` and `selman` field
remains null. This dossier supplements the
[existing review ledger](../stellar_designations_review.json) and
[pending review table](../../stellar_designation_review.md). It does not
change catalogue selection, chart labels or scientific acceptance.

The documents retain evidence strength and unresolved questions. Some exact
historical transitions still require primary-source research; modern catalogue
aliases alone do not establish who introduced a designation. This is a
designation-focused investigation, not a complete astrophysical review.

The structured records include a proposal for a future optional report on
interesting objects appearing in a chart. No report generator or runtime
integration is implemented here. Future reporting must retain object scope,
source attribution and uncertainty, and must not promote unreviewed research
to accepted catalogue decisions.
