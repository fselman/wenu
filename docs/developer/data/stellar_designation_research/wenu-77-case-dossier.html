The 77 discrepancies are not 77 errors. Historical constellation sharing, old numbering traditions and system/component scope explain much of the evidence. Some probable misidentifications and unresolved cross-index problems also deserve preservation, with a different status.

Every original case is included below. All 77 Fernando review decisions remain pending. This document classifies evidence and recommends retention; it does not choose canonical labels or implement chart/report behaviour.

Method and practical limits

  • This research classifies the designation disagreements. It is not a comprehensive astrophysical review of every object.
  • Every case was individually checked against the original ledger, catalogue rows/notes and a live SIMBAD identity. Historical depth varies: not every exponent has an established first author or date.
  • Catalogue omission is not negative evidence of historical existence. BSC main name fields omit some Latin letters; Wikidata and WGSN have selective coverage.
  • HYG and BSC agreement must not be counted as two independent historical witnesses without tracing HYG upstream provenance.
  • Superscript numerals can distinguish unrelated stars, components or catalogue numbering traditions. They are not interchangeable with A/B component letters.
  • The κ CrA pair has conflicting HD cross-identifications. The apparent Bayer disagreement becomes a cross-index issue when coordinates are compared; no source was repaired.
  • Research recommendations are distinct from Fernando’s decisions. All 77 ledger statuses remain pending, all decision/Selman fields null, and no repository or chart behaviour was changed.

The repository's audited source bytes were checked against their recorded hashes. Each case's HIP identity was queried in SIMBAD, and relevant catalogue alternatives and BSC notes were inspected individually. Original Bayer tables, Hoffleit's 1979 study, Wagman's 1987 study and an independent Flamsteed reconstruction supplied targeted historical evidence. Specific primary-source locators accompany each case.

Historical aliases, common abbreviations, component labels and disputed misattributions should remain separate data types. The exact first author/date of many superscripts remains open; the dossier does not invent those dates.

Proposed data contract for an optional chart report

  1. Keep preferred display labels separate from historical aliases, disputed attributions and report topics. A valid historical alias can remain reportable even when never selected for a chart label.
  2. Store each assertion with source, source row or page, epoch/edition when known, scope (star/component/subsystem/system/asterism), validity status, confidence and open questions.
  3. Use HIP for the plotted object, plus HD/HR/WDS/component relations where HIP represents a blend. A report topic may target multiple HIP objects or a wider system.
  4. Generate a requested report from the objects actually rendered after field/horizon/magnitude selection. Label visibility should be a separate eligibility option; an unlabelled plotted object can still be interesting.
  5. Deduplicate report topics by event/system identifier, preserve links to each relevant plotted HIP, and explain when additional components are outside the chart.
  6. Offer concise historical notes by default within the optional report, with observing/astrophysical detail and catalogue disputes as separately selectable categories.
  7. Resolve unstable cross-identifications before they enter the automatic name resolver. Unsupported or erroneous aliases can be retained as evidence while remaining ineligible for ordinary query resolution.
  8. Retain citations and editorial/research status in the topic data. Chart-generation time should use reviewed local material, without turning fresh unsupervised database assertions into narrative facts.
  9. A later implementation should first add a curated topic dataset and validate HIP/component targets, then add optional report output and CLI/TOML parity. This dossier proposes the data contract only.
