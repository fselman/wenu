# Test-suite optimization closure (Milestone 49J.3H)

**Status:** Implementation complete; awaiting repeated Mac acceptance.

## Scope

49J.3H closes the accepted 49J.3 test-suite optimization program. It adds no
runtime behavior, cache, fixture, marker change, test deletion, or performance
threshold. It records the retained fault models from every bounded slice and
installs durable test-file placement and growth rules in contributor authority.

The committed suite currently has 188 `test_*.py` files. This milestone does
not reorganize them retrospectively. Future tests default to the closest file
that owns the same stable responsibility; a new file requires a new durable
component, boundary, public route, scientific oracle, isolation obligation, or
materially different environment/gate. Files are named for architecture, not
milestones, bugs, or pull requests.

## Closure acceptance

Fernando's 49J.3G acceptance established 2,109 routine tests with 24 deselected
in 26.54 seconds and all 2,133 tests in 76.85 seconds. Final closure requires
three fresh routine runs and three fresh complete runs on Mac, reporting counts,
medians, and ranges. It also requires the documentation contract, one reverse
and isolated order check for the shared catalogue consumers, and confirmation
that the working tree is clean. Timings remain characterization evidence, not
enforced thresholds.

The coordinate-system guide was reviewed and remains current because this
documentation-only placement policy changes no scientific meaning, provenance,
coordinate, observer, frame, epoch, equinox, installed interface, or output.

**Runtime effect:** None.

**Test behavior effect:** None.
