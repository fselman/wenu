Wenu observing catalogue source acquisition v1 — 2026-10-13

18 source-table files covering 13 distinct requested catalogues/lists; Best of the NGC is recorded as an alias of SAC, not a second independently verified selection.

observing_sources_v1.json contains source URLs, publisher/edition notes, retrieval times, byte counts, SHA-256 hashes and extraction provenance. validation_counts_v1.json records actual downloaded membership counts.

These are acquisition/review sources, not a clean Wenu target catalogue. Existing chart catalogues, parameter policies and source classifications are not replaced. Public download is not assumed to grant a redistribution licence.

Abell is original scanned Table 2 (86 entries, pages 268-269), not OCR-accepted numeric coordinates. SAC/Messier/Caldwell CSVs retain factual table fields only. Southern Herschel and planetary lists are included. Barnard TSVs include original coordinate-system metadata and notes.

See docs/user_guide/curation.md in fselman/wenu for the full corrected inventory and future curation boundaries.
