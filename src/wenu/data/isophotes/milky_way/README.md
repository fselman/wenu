# Milky Way isophotes

The canonical GeoJSON snapshot comes from D3-Celestial `data/mw.json` at Git blob `ce06eaa01d80a4eed149c538d2d162c919b58a84`. It is distributed under the included BSD-3-Clause licence. Coordinates are longitude/latitude degrees in the source celestial frame.

Runtime loading uses five mechanically exported, plain-text, single-feature
GeoJSON files: `milky_way_ol1.geojson` through `milky_way_ol5.geojson`. The
combined `milky_way_d3.json` remains the pinned canonical source snapshot.
